# Examples

First choose the right context: [without an attachment](without-attachment.md), [with an attachment](with-attachment.md), or [project setup](../project-context/README.md). The task-only examples below assume project instructions are already loaded.

| Task             | Prompt                                                                       |
| ---------------- | ---------------------------------------------------------------------------- |
| UI fix           | Fix /parties: keep the action buttons on one line.                           |
| Behavior bug     | Fix login: entering from port 3001 redirects to port 3000 after signing in.  |
| New feature      | Add phone-number search to /parties.                                         |
| Component change | Add a loading state to the payment button and prevent duplicate submissions. |
| Refactor         | Extract the party filters for reuse, preserving current behavior.            |
| Explanation only | Explain how /parties loads and filters records. Do not edit code.            |
| Plan only        | Plan the date-filter fix. Do not edit code yet.                              |

Add screenshots, reproduction steps or product constraints only when they supply missing facts. The loaded project contract already covers rule selection, impact assessment, verification and reporting.
