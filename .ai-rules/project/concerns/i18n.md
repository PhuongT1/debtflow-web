# Debtflow I18N

**Activate:** i18n changes in Debtflow; load only this selected local extension.

- Locale is a global preference selected by the Shell. Propagate it to embedded MFEs through the versioned platform message contract without reloading the entire page.
- Standalone MFEs must initialize from their locale cookie/default and continue to work when no host is present.
- Standalone language controls use a dropdown with a current-locale trigger and Vietnamese/English choices. React apps reuse `AppLocaleMenu` from `@debtflow/react-ui`; Angular uses its keyboard-accessible equivalent with the shared typography tokens. Keep standalone header labels domain-specific (Partners/Payments); the Platform alone uses Web công nợ.

Reusable policy: [i18n](../../core/concerns/i18n.md).
