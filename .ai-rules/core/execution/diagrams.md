# Diagram Guidance

**Activate:** viewing or maintaining an optional workflow diagram. Routine execution reads the selected rules directly; it does not require diagrams or a specific viewer.

Select a step to read its canonical instructions. If clickable nodes are unavailable, use the detail links below the diagram. Read only triggered steps; uncertainty about permission or impact stops dependent edits. Approval does not establish compatibility. Failed verification returns to investigation; unavailable checks must be reported, never marked passed.

A diagram mirrors the workflow; it is not a second policy body or an executable classifier. Keep each action linked to its detailed rule module and verify links after moves.
