# Resolve Project Context

**Activate:** after instruction access is established and before selecting implementation details. Reuse confirmed context when it has not changed.

1. Read the short [project profile](../../project/README.md). It records owners, installed framework/router/language choices, commands and local extension triggers. Do not read every linked owner or extension.
2. Confirm the target from manifests, configuration and source evidence. React does not imply Next.js; Next.js does not imply App Router; Angular does not imply a standalone migration. Do not assume a monorepo, alias, package manager, design system or supported locale pair.
3. Load only the matching owner instructions and local topic extension. Apply reusable workflow/implementation rules alongside those concrete contracts.
4. A project extension supplies local facts and explicitly documented choices; it does not silently waive scope, impact, secret-handling or approval requirements. Resolve material conflicts with [scope/approval](approval.md), respecting higher-priority and explicit user instructions.
5. If the profile is incomplete, inspect bounded repository evidence before asking. Missing facts are not permission to invent commands or perform an architecture/library migration. Propose the smallest profile correction when needed for adoption.

For the affected responsibility, inspect manifests/configuration, the nearest owner instructions, a comparable implementation, and actual consumers. Resolve where the project puts equivalent code and how it styles, binds data and verifies it before choosing a location or dependency. A missing library, shared package, locale system or deployment mode is not a request to add one. If recorded facts disagree with source/configuration, report the mismatch and establish the current contract before dependent changes; do not silently override an explicit project policy. Existing implementation is evidence, not permission to copy a defect.

**Exit:** target owner, relevant stack and executable checks are known, or a specific missing decision/access is explicit. Return to the selected workflow without opening unrelated framework modules.
