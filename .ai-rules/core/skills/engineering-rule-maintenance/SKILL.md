# Rule Maintenance

Establish the [repository instructions](../../../README.md) and [project context](../../../project/README.md), then select only the rules relevant to this task.

Use the [canonical task workflow](../../workflows/rule-maintenance/README.md) for task stages and conditional rules. Do not recursively load every reference.

Choose the canonical owner: common decision process in core, concrete project choices in project. Update selectors, native projections, source links and relevant checks together.

If delegation is available and permitted, use the [coordination contract](../../agents/README.md); otherwise perform the same responsibility in the current agent. A skill does not grant extra scope or permission.
