# Component Create

Establish the [repository instructions](../../../README.md) and [project context](../../../project/README.md), then select only the rules relevant to this task.

Use the [canonical task workflow](../../workflows/component/create/README.md) for task stages and conditional rules. Do not recursively load every reference.

Resolve placement, styling, language and exports from the current project. Reuse or extend a compatible primitive before creating an alternative; do not impose a design system or shared package.

If delegation is available and permitted, use the [coordination contract](../../agents/README.md); otherwise perform the same responsibility in the current agent. A skill does not grant extra scope or permission.
