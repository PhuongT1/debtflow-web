# Partner Ops Internationalization

- Use `next-intl` with the current App Router configuration and no locale route segments.
- Translation messages live in `messages/en.json` and `messages/vi.json`. Add the same semantic key to both files in one change.
- Use `useTranslations` and `useFormatter` for client UI. Do not add feature-local translation maps or manually format locale-sensitive dates/numbers.
- Standalone mode initializes locale from cookie/default. Embedded mode receives host locale through the platform bridge and updates without a document reload or data refetch.
